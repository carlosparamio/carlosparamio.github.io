# Redesign Contract: Agentic Infrastructure Lab

Branch: `redesign`

## Intent
Keep the current content model and site structure, but reposition the visual identity around senior software and cloud architecture with a credible AI-era layer: coding agents, AI-guided delivery, and scalable production systems. AI should support the story, not replace the 20+ year architecture foundation.

## Chosen Direction
A+B from the shape exercise:

- **A: Agentic Infrastructure Lab** for selected visual energy: dark-first, neon signals, technical atmosphere.
- **B: Modern Architect Console** for hierarchy and tone: senior, credible, direct, architecture-led rather than hype-led.
- **Agent Loop Oscilloscope** for the hero graphic: architecture as the control loop, AI as one signal within cloud delivery and production feedback.

## Visual Principles
1. **Dark-first control plane**: the default impression should feel like an operational system map, not a generic marketing page.
2. **Neon with restraint**: phosphor green and cyan are signals, not decoration. Avoid purple-blue SaaS gradients.
3. **Architecture before spectacle**: diagrams, labels, and motion should explain systems thinking.
4. **Senior copy, no AI hype**: use concrete phrases like LLM harnesses, evaluation gates, tool boundaries, observability, and cloud scale.
5. **Keep credibility anchors**: preserve current navigation, testimonials, projects, and professional background.

## Typography
- Body remains readable and professional.
- Display typography can shift more technical and compact.
- Avoid terminal cosplay: no monospace as the main personality unless it has a specific functional role.

## Hero Contract
The hero should communicate in under 10 seconds:

> Carlos designs agentic software systems that can be reviewed, operated, and scaled.

Hero ingredients:
- Dark infrastructure atmosphere.
- Oscilloscope/control-loop visualization.
- Copy led by software and cloud architecture, with AI-assisted delivery as the current evolution.
- CTAs leading to selected work and architecture background.

## Copy Direction
Primary headline:

> Software architecture for cloud and AI systems

Supporting line:

> 20+ years designing scalable software and cloud platforms. I now apply that architecture discipline to AI-assisted delivery, agent workflows, and systems that need to survive real production constraints.

## Capability Language
- Cloud Architecture at Scale
- Technical Leadership
- AI-Assisted Software Delivery
- Agentic Systems Exploration

## Guardrails
- No glassmorphism cards.
- No purple-blue gradients.
- No emoji icons.
- No decorative card shadows.
- No generic “unlock/supercharge/transform” AI copy.
- Preserve accessibility, reduced motion, and Astro build health.
